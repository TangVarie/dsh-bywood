# 芭梧 BYWOOD 视觉系统

按 **BYWOOD 设计系统 v5.8.2**（色板 v5.1 · 版式 v4.0 · 界面轨）重绘 DeepSeek Harness 的整套界面，并把产品自身的标志、词标、标题和图标换成芭梧。

## 它做了什么

| 层 | 做法 |
|---|---|
| 色板 | 通过主题服务的 `overrideTokens()` 把 138 个 `--dsw-alias-*` 别名 token 叠在 light/dark 之上。画布 `#F3F4F6`/`#0F1318`、表面 `#FFFFFF`/`#1B222B`、主色深青 `#1E5754`/`#6AC1BD`、赭石强调色、四阶文字、发丝线与语义色全部取自 `palette.json`。组件不写第二套深色值。 |
| 圆角 | 保留 DeepSeek Harness 自带尺度（4/8/12/16/20/28）。BYWOOD 原文是直角制度；你对比直角与柔和直角两版后选择保留默认圆角，这是全项目唯一按你的判断偏离规范的地方。 |
| 深度 | 浮层、菜单、Toast、模态一律去掉投影与毛玻璃，改由 1px 描边 + 明度差成形；阴影只留给抽屉。 |
| 字体 | 界面 PingFang SC → Hiragino Sans GB → Microsoft YaHei；代码与终端使用等宽字体栈；标题走衬线显示层（宋体族），数字用等宽数字、表格与统计胶囊对齐。 |
| 版式 | 对话正文按刊物化处理：标题层级、1.7 行距段落、悬挂列表、主色竖线引用块、横向发丝线表格（无竖线无底色）、代码块与 diff、细滚动条。 |
| 组件 | 设置对话框、工具调用卡、思考块与步骤组、轮次过程与变更卡、代码块横幅、菜单与下拉、右侧栏、运行指示均按同一套 token 与规则收口；像素鲸鱼动画已移除。 |
| 文案 | 编辑器占位改为「说说这一轮要推进什么, / 调用指令, @ 文件或对话」；其余功能语义文案保留。 |
| 品牌 | 侧栏与空白会话主视觉换成芭梧山形方标；品牌名改为「芭梧 BYWOOD」；浏览器标题、favicon、apple-touch-icon 同步为芭梧。桌面快捷方式 / 托盘 / 窗口图标为圆角芭梧图标（22% 圆角，四带山形）。 |

## 安装与更新

插件通过自己的 DeepSeek Harness 插件索引发布：

```
https://raw.githubusercontent.com/TangVarie/dsh-bywood/main/index.json
```

在「插件 → 发现 → 添加索引源」里添加一次，然后安装主题。以后有新版本，同一页会出现「更新」；插件本身不检查版本、也不下载代码。

页面根元素上的 `data-bywood-version` 会写成当前加载的版本号，排查「更新后还是旧样式」时先看它。

## 怎么用

1. 安装后即时生效（客户端 bundle 由页面惰性加载）。
2. 浅色 / 深色 / 跟随系统仍可用设置里的「外观」切换——两套色板都已按 BYWOOD 映射，切换只翻转 token。
3. 卸载插件后所有 token、样式表、品牌位与 favicon 都会随效果清理恢复原样；标题会由外壳重新写回。

## 已知边界

- BYWOOD 设计系统没有为「聊天 / 输入框」定义构件（其 B 级实验区）。本插件按同一套 token 与规则推导：用户消息用温润圆角气泡 + 淡青底（`--dsw-specific-bubble`，取自 BYWOOD `tint-primary`）、输入区用 surface + 发丝线，未新增色值。
- BYWOOD 没有语法高亮色板，代码高亮仍由语法主题负责；本插件只统一下层界面色。
- 品牌青 `#7ED1CD` 按设计系统规定只做面（`--color-field-brand`），不作文字、描边或图标前景。
- 面板拖拽落位时的遮罩自带约 150ms 磨砂，外壳没有暴露覆盖钩子——这是本插件唯一保留的例外。
- 桌面图标通过替换安装目录的资源文件（托盘 / 窗口图标）与桌面快捷方式完成，**不修改 `app.asar`**（曾因重打包导致启动空白页）；应用内欢迎页与更新对话框未改动。

## 样张

`docs/preview.html` 是同一套 token 与规则画出的静态样张（含浅 / 深色切换），用于在没有截图权限时核对视觉语言；它不参与运行时。
